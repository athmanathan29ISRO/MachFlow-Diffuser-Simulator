# MachFlow – Diffuser Simulator

A Python-based engineering simulation tool for analysing subsonic and supersonic diffuser flow.

## Features
- Isentropic flow calculations
- Area–Mach number relationship
- Normal shock analysis
- Oblique shock calculations
- Subsonic diffuser analysis
- Idealized supersonic diffuser analysis
- Engineering validation checks
- Interactive Streamlit interface
- Mach number visualization

## Technologies Used
- Python
- NumPy
- SciPy
- Matplotlib
- Streamlit
- Pandas

## Installation

```bash
git clone https://github.com/YOUR-USERNAME/MachFlow-Diffuser-Simulator.git
cd MachFlow-Diffuser-Simulator
python -m pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run main.py
```
